功能特性

六项能力，覆盖「采集 → 归档 → 阅读 → 导出」

不是又一个稍后读工具：它把正文、图片、视频原文件一起落到你自己的硬盘上。

复用登录态，不存密码

复用本机 Chrome / Edge 已保存的会话与 X 登录，不写设置、不写日志、不上传。

  • 优先连接本机 CDP 会话
  • 不修改、不重启你的日常浏览器
  • 只有无法复用时才需要手动登录一次

双源归档：X + 公众号

X 官方 Article 与含长文正文的帖子，加上微信公众号文章，正文清洗后统一入库。

  • 支持单篇链接、分享链接、博主主页批量
  • 一次最多 100 条，博主默认最近 10 篇
  • 图片存原图，视频优先 MP4 / HLS 合并

队列可控，断点可续

下载与导出都在任务队列里跑，出错不丢已完成的部分。

  • 暂停在安全步骤完成后生效
  • 取消保留已完成结果，重试只跑未完成项
  • 退出后未完成任务显示「等待继续」

三栏资料库

按博主、日期、完整性筛选，全文搜索，阅读视图可调字号并批量导出。

  • 界面字号 14–18px，正文 16–24px
  • 回收站与批量操作
  • 离线状态也能翻已归档的图文

六端同阅，后端可选

服务端是唯一权威数据源；桌面端内嵌本机服务面，供扩展与手机直连。

  • 桌面采集 → Web 看板 → H5 / Android 阅读
  • 内嵌服务面 127.0.0.1:17321
  • 后端未启动时客户端照常可用

成套导出与命令行

一篇长文导出 Markdown / DOCX / PDF，保留结构与图片，方便二次整理。

  • 三种格式一次选中，批量执行
  • 图片、视频随导出一起带走
  • 命令行单次归档，任务结果与完整性一并输出

安装使用

四步跑通第一次归档

桌面端是唯一持有登录态的执行端，其余端在需要多设备时再接服务端。

1

装桌面端

按你的系统下载 DMG / EXE / DEB，安装后打开 DownX。macOS 构建为 ad-hoc 签名，首次启动需放行。

# 若提示「已损坏」或无法验证开发者
xattr -dr com.apple.quarantine /Applications/DownX.app
2

复用浏览器登录

设置里选择 Chrome 或 Edge，点「复用浏览器登录」；系统询问钥匙串访问时允许读取浏览器会话。不修改、不重启你的日常浏览器。

系统设置 → 采集 → 复用浏览器登录
# 无法复用时再点「打开采集窗口」手动登录一次
3

粘贴链接开始下载

官方 Article 链接、文章分享链接、博主主页或公众号链接都可以，多行最多 100 条；任务进度在「任务管理」里看。

默认保存目录：我的待办/downX/x-article
# 支持多行批量，单次最多 100 条；博主主页默认最近 10 篇
4

阅读、导出、上多端

在三栏资料库里筛选、批量导出 Markdown / DOCX / PDF；需要多设备时启动 xdoc-api 与 Web 前端，扩展与手机即可接入。

# 命令行单次归档（先退出桌面应用）
/Applications/DownX.app/Contents/MacOS/downx \
  --archive https://x.com/user/status/123 \
  --save-dir "/绝对路径/X"
按需选择：只想在单机归档阅读，装桌面端就够了；要手机同步或团队看板，再叠 Web 服务端与前端。

部署到服务端

需要多设备同步或团队看板时，叠一层 Web 服务端。

  • 1. 启动 APIJava 17 · java -jar xdoc-api-3.1.5.jar
  • 2. 解压前端放至任意静态目录，指向 API 地址
  • 3. 解压 H5手机端访问同一 API
  • 4. 装扩展解压后「加载已解压的扩展程序」
  • 说明后端可选：未启动时桌面端照常可用
